CURRENT DATE: 2026.

MONETISATION CONTEXT:
This app uses Banner Ads + Interstitial Ads + Rewarded Ads (AdMob) + Subscription via RevenueCat (Google Play Billing + StoreKit 2).
Monthly: ~$1.99 | Annual: ~$9.99 | 7-day free trial on annual.
Every feature MUST be classified: FREE | PAID | FREE_WITH_REWARDED_AD.

AD PLACEMENT RULES TO ENFORCE (do not violate):
- Banner: list / feed / results screens at the bottom — never on core task screens.
- Interstitial: only at natural breaks (task complete, back-to-home). Cap: 1 per 8 minutes.
- Rewarded: user-initiated only, unlocks the feature for 24h.
- All ads: hidden instantly and permanently on paid subscription.

REQUIRED FEATURES TO SPEC (always include these regardless of app type):

1. Onboarding Flow (P0, FREE)
   — 3 screens max, value before sign-up, no forced account creation.
   — Progressive permission requests (notifications only after value shown).

2. Core Loop Feature(s) (P0, FREE with soft caps)
   — The main thing the app does — spec completely.

3. User Account / Profile (P1, FREE)
   — Optional sign-up, what data is stored, sync behaviour.
   — Free: local only | Paid: cloud sync across devices.

4. Settings Screen (P1, FREE)
   — Notification preferences, account, subscription status, "Restore Purchases" button (REQUIRED by both app stores), privacy policy link, terms link.

5. Subscription / Upgrade Flow (P0, PAID)
   — Paywall screen: what's shown, in what order.
   — Google Play Billing integration via RevenueCat.
   — Apple StoreKit 2 integration via RevenueCat.
   — "Restore Purchases" flow (required by Apple).
   — 7-day free trial on annual plan.
   — What happens on: trial start, trial end, successful purchase, failed purchase, cancellation, refund, resubscription.

6. Rewarded Ad Feature(s) (P1, FREE_WITH_REWARDED_AD)
   — 1–3 premium features accessible via rewarded ad.
   — 24-hour unlock after watching.
   — Graceful fallback if no ad available: "No ad available right now, try again in a few minutes" — never hard-block.

7. Notification System (P1, FREE)
   — What notifications are sent, when, what the copy is.
   — User control: which notifications to enable.
   — Deep link targets: each notification taps into a specific screen.

8. Offboarding / Data Export (P2, PAID)
   — User can export their data.
   — Account deletion flow (required by Apple + Google policies as of 2025).
