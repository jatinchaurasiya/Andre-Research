RESEARCH TASKS (use web search):

DESIGN PHILOSOPHY TO ENCODE:
- Calm technology: the app should feel helpful, not urgent.
- One primary action per screen — always clear what to do next.
- Visual hierarchy before decoration — spacing and weight communicate importance; colour is used sparingly for signal.
- Native feel on each platform: Material 3 on Android, Human Interface Guidelines on iOS — with a consistent cross-platform brand layer on top.
- Dark mode as first-class — design dark first, light second.

MONETISATION UX RULES TO ENCODE IN THE BRIEF:
- Ads styled to feel native: same corner radius, similar padding as app cards — not a jarring foreign element.
- Rewarded ad CTA: a premium-feeling button, never desperate. "Watch a short video to unlock [feature] for 24h →".
- Paywall: minimal, confident, value-led. Show 3 premium features with icons, the price, and the trial offer. Clean. Not pushy.
- "Remove Ads" framing: position it as a premium benefit, not an apology for having ads.

For each component below, specify: visual appearance, states, exact dimensions, and the content/behaviour rules.

### 3.1 Primary CTA Button
Height: 52dp | Corner radius: 12dp | Full width on mobile.
States: default, hover/pressed (10% darker), loading (spinner), disabled (40% opacity).

Padding: 16dp horizontal. Loading: replace text with 20dp spinner.

### 3.2 Secondary Button
Same height. Outlined style. Primary colour border + text.
States: same as primary but inverted colours on press.

### 3.3 Text Input
Height: 52dp | Corner radius: 12dp | Border Default at rest.
Focus: Border Strong + Primary-colour label.
Error: Error-colour border + error message below.
Label: floats above on focus (Material 3 style).

### 3.4 Standard Card
Background: BG Surface | Corner radius: 12dp | Padding: 16dp.
No shadow in dark mode (use border instead: Border Default).
Pressed state: BG Elevated.

### 3.5 Bottom Navigation Bar
Height: 56dp + safe area | BG Surface background.
4–5 items max. Active: Primary-colour icon + label. Inactive: Text Secondary icon + label.
No border — use elevation shadow 2.

### 3.6 Top App Bar
Height: 56dp | BG Primary background | Back arrow or menu.
Title: Heading size. Right actions: icon buttons 48dp touch target.

### 3.7 Bottom Sheet
Corner radius top: 24dp | Handle: 4dp × 32dp, BG Surface.
Drag to dismiss enabled. Scrim: 60% black.

### 3.8 Empty State
Centred vertically and horizontally. Illustration or icon 80dp.
Title: Heading. Body: Body Secondary colour.
CTA: Primary button — specific action, not generic "Get started".

### 3.9 Loading Skeleton
BG Surface base. Animated shimmer: lighter colour sweeping L→R.
Match the exact shape of the content it replaces.

### 3.10 Toast / Snackbar
Bottom of screen, 16dp from edge. BG Elevated. Corner radius: 12dp.
Auto-dismiss: 3 seconds. Max 2 lines. Optional action button.

### 3.11 Ad Banner Container
Background: BG Surface (same as cards — NOT a different colour).
Corner radius: 12dp | 16dp horizontal margin.
Label: "Ad" in Caption style, Text Disabled colour, top-right.
Same visual weight as a regular card — feels native, not foreign.

### 3.12 Rewarded Ad CTA Button
Secondary button style with a crown/sparkle icon prefix.
Copy format: "✦ Watch to unlock [feature] →".
NEVER uses urgent colours — same calm palette as rest of app.

### 3.13 Paywall Screen Components
Feature list items: checkmark icon in Primary colour + Body text.
Price display: Display size for price, Caption for per-month breakdown.
Trial badge: Small rounded pill in Success colour.
Primary CTA: "Start free trial" or "Unlock Premium".
Secondary: "Maybe later" in Text Secondary, no button border.

## Section 6: Paywall Design Brief

**Design philosophy:** Confident, minimal, value-forward. This screen should feel like discovering something valuable, not being pressured into a purchase.

**Layout structure:**
1. App icon or hero illustration (not mandatory — only if it adds warmth).
2. Headline: "[The outcome they want]" — not "Go Premium".
3. 3 feature highlights: icon + short label + one-line benefit.
4. Pricing section: Annual plan prominent, monthly plan secondary.
5. Trial callout: success-colour pill "7 days free".
6. Primary CTA: "Start free trial" — Primary button, full width.
7. Terms: Caption size, Text Disabled — auto-renews, cancel anytime.
8. "Maybe later": Text link below CTA, no button styling, Text Secondary.

**What NOT to include:**
- No countdown timers.
- No "X people upgraded today" fake social proof.
- No before/after screenshots cluttering the screen.
- No more than 3 feature highlights (cognitive overload).
- No fine print hiding the price.

**Success state after purchase:**
- Celebration animation — confetti or checkmark pulse.
- Message: "You're all set! [App name] Premium is now active."
- CTA: "Let's go →" — returns to home with ads hidden.
